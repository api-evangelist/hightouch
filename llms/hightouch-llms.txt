# Hightouch Documentation

> Hightouch is a data and AI platform for marketing and personalization. It helps teams activate customer data from their data warehouse to business tools through reverse ETL, audience building, identity resolution, and AI-powered campaign optimization.

**MCP server:** For structured search and page-level read access, connect to the Hightouch Docs MCP endpoint at `https://hightouch.com/docs/api/mcp` (Streamable HTTP, no authentication). See [Docs for AI tools](https://hightouch.com/docs/developer-tools/agent-resources) for setup instructions.

## Getting started

- [Data activation concepts](https://hightouch.com/docs/getting-started/concepts): Learn the foundational concepts in Hightouch—sources, models, schema, syncs, destinations, and change data capture—that power Reverse ETL and the Composable CDP.

## Models

- [Create models with the SQL editor](https://hightouch.com/docs/models/sql-editor): Create Hightouch models using the SQL editor.
- [Create models with the table selector](https://hightouch.com/docs/models/table-selector): Create Hightouch models using the table selector which queries existing tables and views within your source.
- [Data types and casting](https://hightouch.com/docs/models/data-types-casting): Third-party APIs require the data you send to be of a specific data type. Unless otherwise specified, Hightouch takes the data from your source and leaves the data type unchanged to send to your destination. You can choose to cast data into different types using SQL.
- [Match Booster on models](https://hightouch.com/docs/models/match-boosting): Configure Match Booster on a model to enrich your data with additional identifiers.
- [Models overview](https://hightouch.com/docs/models/creating-models): Create Hightouch models using the SQL editor or the table selector which queries existing tables and views within your source.
