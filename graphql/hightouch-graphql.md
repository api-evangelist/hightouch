# Hightouch GraphQL API

Hightouch is a composable Customer Data Platform (CDP) and data activation platform that syncs data from cloud data warehouses such as Snowflake and BigQuery to over 300 SaaS destinations. The platform supports Reverse ETL, audience segmentation, journey orchestration, real-time personalization, AI Decisioning, identity resolution, first-party event collection, and ad campaign management. Hightouch exposes a REST-based Resource API for programmatic management; a native public GraphQL endpoint is not currently documented. This conceptual GraphQL schema represents the platform's core data model derived from its REST API, product documentation, and feature surface.

**Endpoint:** No native public endpoint — conceptual schema based on REST API surface and product documentation

**Documentation:** https://hightouch.com/docs/api-reference
